========================================================================
  TV Local Streaming Server 
========================================================================

本ソフトウェアは、EDCB（EpgTimer / EpgDataCapBon）から取得した放送波ストリームを
ローカルネットワーク内でHLS配信し、ブラウザで視聴するためのサーバーツールです。

------------------------------------------------------------------------
■ 1. 動作環境・必須要件および初期設定
------------------------------------------------------------------------
本ソフトウェアを実行する前に、以下のコンポーネントがインストールされ、
正しく設定されている必要があります。

1. Node.js (v18 以上推奨)
   - インストール後、環境変数 PATH が通っていること。

2. FFmpeg
   - インストール後、環境変数 PATH が通っていること。

3. EDCB の設定 (EpgTimer / EpgDataCapBon)
   ■ EpgTimerSrv の設定:
     - EpgTimer.exe の「設定」＞「動作関係」＞「ネットワーク設定」を開き、
       「EpgTimerSrvのNW接続を許可する（デフォルト Port 4510）」を有効にしてください。
   
   ■ EpgDataCapBon の設定 (映像配信のために必須):
     - EpgDataCapBon.exe を起動し、画面右上の「設定」を開きます。
     - 「ネットワーク設定」タブを選択します。
     - 「TCP送信」の項目にある「送信先一覧」に「srvPipe」を追加してください。
       ※ これが追加されていないと、サーバーへ映像データが送られず視聴できません。

※ 起動時に「StartTray.bat」がこれらの依存環境およびネットワーク接続を自動チェックします。


------------------------------------------------------------------------
■ 2. 起動方法
------------------------------------------------------------------------
1. 本フォルダ内の「TvLocFree.bat」をダブルクリックして実行します。
2. 依存環境のチェックが成功すると、画面右下のタスクトレイにアイコンが常駐します。
3. 自動的に Web サーバーおよびストリーミング機能がスタートします。
4. トレイアイコンを右クリックすることで、以下の操作が可能です。
   - ▶ Start Server : サーバーの起動
   - ■ Stop Server  : サーバーの停止
   - ❌ Exit        : トレイマネージャーの終了
