# tv-loc-free
TS抜き環境でTVを遠隔で観る為のアプリです。  
動画ファイルの視聴や録画機能はありません。  
Jellyfin 用の [インターフェース](https://github.com/kurenai-dev1/tv-loc-free/blob/main/Jellyfin.md)もテスト用に付けました。  
**私はコードをほとんど書いてません。大部分Geminiが書いてます。**  

# 目指したもの
* ともかくシンプル。
* 通信量、バッテリー消費を出来るだけ少なく。
* 安定性。
* 誰でも改変できるようにGeminiに作らせる。

わからない事や困った事があったら Gemini(無償版で可)に聞いてください。  
その際は、最初にこの概要をコピペしてGeminiに教えて下さい。

# 設計
* 今も開発が継続しており、動作が安定しているEDCBを使う。
* 開発言語は、Node.js+React とWEBアプリではメジャーな構成。
* バックエンドとフロントエンドを明確に分ける。
* CSSはフレームワークを使わず、入れ子を使いスコープを明確にする。
* 家庭内のローカルネットワークで使う。
* 外出先からは、TailScale(VPN)を使う。
* 複数端末からの視聴を可能にするビジターモードを設ける
* メディアサーバーJellyfinへのインターフェースの提供。
* **録画機能は付けない。**

録画予約や録画、既存の動画ファイルの再生は、同じアプリで行うべきではないと考えています。    
チューナーを使うライブ配信に比べると注力する所が異なるからです。  
また、一緒にすることでソースコードがスパゲティ状態になるのを防ぎます。  
既存の動画再生は、Jellyfin を推奨します。TV視聴用にインターフェースも追加しました。  
もう人がメンテを行う時代じゃない。AIにお任せ。💛💛💛  

# 技術情報
EDCBの録画環境が既にある前提。
EDCBは、チューナーの起動と放送局選択、TSストリームの転送を担う。  
その為、EpgTimerが動いている必要があり、ネットワーク転送設定がされていることが必要。  
<img width="30%" alt="Image" src="https://github.com/user-attachments/assets/114b471c-7948-47b3-a660-76c959b07b0a" />  
EDCBのAPIを利用するので、利用許可のチェックも必要。
TSストリームから、エンコードとm3u8(ライブ配信の形式)への変換は全てFFmpegが行ってくれる。  
端末側のプレイヤーは、SPA(Single Page Application)。  
m3u8 の再生には、hls.js を使う。(iPhoneでは最適化)   
放送局情報は、EDCB配下のChSet5.txtを直接読んでいる。  
あえて**開始・終了ボタン**を付けている。  
これは、複数端末から視聴した場合、チャンネルの制御を誰がコントロールできるかをうまく解決してくれる。  
終了ボタンを忘れてもEDCBのチューナーが必ず正常に終わるように、端末側からハートビートを送って、  
途切れたらサーバー側が自動で解放するようにしている。  
映像の自動再生は本来、無音でしか出来ないが、学習効果を使って、ほぼ再生できるようにしている。  
映像はマルチビットレートで作成でき、解像度とビットレート、個数が設定できる。(*オプション設定)  
端末では、解像度の種類が選択できる。  
必須では無かったが、現時刻の番組情報もEDCBから取得するようにした。

> [!NOTE]
> サーバーの負荷を考え、デフォルトでは１ビットレートにして、解像度変更はチャネル切り替えと同じ処理にした。  
> その為、**映像の切り替えに少し時間がかかる**。
> サーバーの能力に合わせて選択してください。(.envの修正)

クライアント側の負荷は主に選択した解像度のビットレートで決まると考えられる。  
Intel CPU 環境しか無く、グラボも持っていないのでハードウエアエンコードはQSVしか想定していない。  
FFmpeg を使っているので対応はGeminiに、ffmpeg.js を提示すれば直してくれるはずです。  

# 実行環境
**実行環境は Windows のみ**。(EDCBを使っている為)   
Node.js なので Linux への移植は簡単だと思いますが、私は環境を構築していないので対応出来ません。  
恐らく、EDCBに替えて Mirakurun を使えば良いだけだと思います。

# バイナリの配賦
開発環境だけでも動かせますが、とりあえず配賦版を作成しました。  
backend のExpressサーバーに frontend でbuildしたdistフォルダを置く構成です。  
見栄え的に、バッチファイルで起動してタスクトレイで起動・停止が行えるようにしました。  
この場合のブラウザのURLは、`http://ホストのIPアドレス:3000` になります。  

# 開発環境とテスト
* EDCBの録画環境が動いていること
* FFmpeg をインストールしパスが通っていること
* Node.js のインストール
* 適当なフォルダにダウンロード
* EDBC のEpgDataCap_Bon で名前付きパイプを有効にしておく。

## backend の準備と実行
```bash
cd backend
npm install
# 実行
npm run dev
```
## frontend の準備と実行
```bash
cd frontend
npm install
## 実行
npm run dev
```
## プレーヤーの呼び出し
`http://localhost:5173`  
他の端末からアクセスする際は、Windowsのファイヤーウォールを通過させて下さい。  
遠隔地からは、VPNを使って下さい。お勧めは、無料で使える TailScale です。  

# プログラムの改変
もともと、Gemini無償版で開発しています。  
ただし、無償版では、全てのソースコードを一度に理解させる事はできません。  
まず、概要を送って全体を理解させた後に、対象となりそうなソースコードをGeminiに提示すれば、  
改変後のコードを作ってくれます。
