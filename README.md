# tv-loc-free
TS抜き環境でTVを遠隔で観る為のアプリです。  
この種のアプリはいろいろありますが、単純にTVを観るだけのものが無いので作りました。  
**私はコード一切書いてません。全部Geminiに書かせてます。**  

# 目指したもの
* ともかくシンプル。
* 通信量、バッテリー消費を出来るだけ少なく。
* 誰でも改変できるように全てGeminiに作らせる。

わからない事や困った事があったら Gemini(無償版で可)に聞いてください。  
その際は、最初にこの概要をコピペしてGeminiに教えて下さい。

# 設計
* 今も開発が継続しており、安定しているEDCBを使う。
* 開発言語は、Node.js+React と最もメジャーな構成。
* 家庭内のローカルネットワークで使う。
* 外出先からは、TailScale(VPN)を使う。
* 番組情報、録画機能は無い。

既存の動画ファイルの再生は、同じアプリで行うべきではない。    
チューナーを使うライブ配信に比べると単純で注力する所が異なる。  
一緒にすることでソースコードがスパゲティ状態になる。

# 技術情報
EDCBは、チューナーの起動と番組選択、TSストリームの転送を担う。  
その為、EpgTimerが動いている必要があり、ネットワーク転送設定がされていること。  
<img width="30%" alt="Image" src="https://github.com/user-attachments/assets/114b471c-7948-47b3-a660-76c959b07b0a" />  
EDCBとのAPIはMonomiTVを参考にさせてもらっている。  
※ GitHub の EDCBのAPI情報はあまり参考にならない。  
TSストリームから、エンコードとm3u8(ライブ配信の形式)への変換は全てFFmpegが行ってくれる。  
m3u8 の再生には、hls.js を使う。  
端末側のプレイヤーは、SPA(Single Page Application)。  
EDCBのチューナーが正常に終わるように、端末側からハートビートを送って、途切れたらサーバー側が解放するようにしている。  
映像の自動再生は本来、無音でしか出来ないが、学習効果を使って、ほぼ再生できるようにしている。  
映像はマルチビットレートで作成でき、解像度とビットレート、個数が設定できる。  
端末では、解像度の種類が選択できる。  
ただし、サーバーの負荷も増えるので、選択できる個数は少ないほうが望ましい。(2個が推奨)  

> [!NOTE]
> サーバーの負荷を考え、デフォルトでは１ビットレートにして、解像度変更はチャネル切り替えと同じ処理にした。  
> その為、映像の切り替えに時間はかかる。

クライアント側の負荷は主に選択した解像度のビットレートで決まると考えられる。  
実行環境は Windows のみ。(名前付きパイプを使っている為)    
※ Node.js なので Linux への移植は簡単だと思いますが、私には環境が無いので対応出来ません。  

# バイナリの配賦
今のところ、開発環境だけの提供です。  

# 開発環境とテスト
* EDCBの録画環境が動いていること
* FFmpeg をインストールしパスが通っていること
* Node.js のインストール
* 適当なフォルダにダウンロード
* EDBC のEpgDataCap_Bon で名前付きパイプを有効にしておく。

## backend の準備と実行
```bash
cd backend
npm install
# 実行
npm run dev
```
## frontend の準備と実行
```bash
cd frontend
npm install
## 実行
npm run dev
```
## プレーヤーの呼び出し
`http://localhost:5173`  
他の端末からアクセスする際は、Windowsのファイヤーウォールを通過させて下さい。  
遠隔地からは、VPNを使って下さい。お勧めは、無料で使える TailScale です。  

# プログラムの改変
もともと、Gemini無償版で開発しています。  
ただし、無償版では、全てのソースコードを一度に理解させる事はできません。  
まず、概要を送って全体を理解させた後に、対象となりそうなソースコードをGeminiに提示すれば、  
改変後のコードを作ってくれます。
